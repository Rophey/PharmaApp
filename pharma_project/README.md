# PharmaApp - Информационная система управления процессом таблетирования (ИС УПТ)

## Описание

Информационная система для автоматизации и контроля процесса таблетирования на фармацевтическом предприятии в соответствии с требованиями GMP и FDA 21 CFR Part 11.

## Стек технологий

- **Backend:** Python 3.10+, Django 5.2
- **Database:** PostgreSQL 13+
- **Frontend:** HTML5, CSS3, JavaScript
- **Отчёты:** openpyxl (Excel), CSV

## Роли пользователей

- Системный администратор - управление пользователями и настройками
- Главный технолог - создание и утверждение MBR
- Технолог - запуск партий в производство
- Оператор - выполнение операций
- Сотрудник ОКК - контроль качества
- Начальник ОКК - решение по отклонениям
- Директор - отчёты и аналитика

## Установка и запуск

### 1. Создание виртуального окружения

```bash
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка PostgreSQL

Создайте базу данных `pharma_db` и пользователя:

```sql
CREATE DATABASE pharma_db;
```

Настройте подключение в `pharma_project/settings.py` (DATABASES).

### 4. Миграции

```bash
cd pharma_project
python manage.py makemigrations
python manage.py migrate
```

### 5. Создание суперпользователя

```bash
python manage.py createsuperuser
```

### 6. Запуск сервера

```bash
python manage.py runserver
```

Откройте браузер и перейдите по адресу `http://localhost:8000`

## Альтернативный запуск (PowerShell)

```powershell
cd PharmaApp\pharma_project

```

## Функционал

### MBR (Master Batch Record)
- Создание рецептур
- Управление версиями
- Утверждение с электронной подписью

### EBR (Electronic Batch Record)
- Запуск партий из MBR
- Внесение данных с оборудования
- Многоуровневая система оповещений

### Контроль качества
- Задания для ОКК
- Регистрация отклонений
- Решения по отклонениям

### Аудит
- Неизменяемый журнал действий
- Электронная подпись документов

### Отчёты
- Отчёт по выпуску продукции
- Отчёт по отклонениям
- Экспорт в Excel/CSV
